## Mechanism

Chrome cannot place `action.default_popup` over the webpage with the site visible through glass, and `default_popup` closes on page click. The implemented surface is a content-script **closed Shadow DOM** host (`#n-eye-overlay-host`). N-Eye CSS is inlined into the shadow tree. Website CSS cannot restyle it. Overlay CSS does not restyle the page. Host is `position: fixed` with no layout shift.

More uses `chrome.sidePanel.open({ tabId })`. Because that API needs a user gesture on an extension page, a tiny `web_accessible` iframe (`overlay/open-panel.html`) sits on the More control and calls `sidePanel.open` in the click handler. The service worker also attempts `sidePanel.open` and then unmounts the overlay. No new Chrome **permission**. WAR is not a permission.

## Lifecycle

| Event | Behavior |
|---|---|
| Toolbar click | Toggle overlay on the active tab |
| Run (no owner yet) | Open Side Panel, then start the T011 loop |
| Click the webpage | Overlay stays (unlike `default_popup`) |
| Close overlay | View only. Does **not** cancel, does **not** clear the vault |
| Close Side Panel during a task | Cancel (T011/T012). Vault dies with the owner document |
| Tab switch | Live evidence cleared (T011 TAB_CHANGED) |
